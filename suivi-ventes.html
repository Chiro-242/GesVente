Sauvegarde et transfert

Vos données sont gardées dans l’appareil où vous les saisissez. Pour les retrouver sur un autre appareil (téléphone, ordinateur), passez par un code à copier.

Copier ou importer vos données

Sur l’appareil qui contient les données : cliquez sur « Générer le code », copiez-le et envoyez-le vous (WhatsApp, e-mail…).
Sur l’autre appareil : ouvrez cette même page, collez le code ci-dessous et cliquez sur « Importer le code ». Les données sont ajoutées à celles déjà présentes, rien n’est effacé.
